# Batumi Invest

ქართული, მობილურზე მორგებული უძრავი ქონების ვიტრინა Django-ზე. შეიცავს საძიებო ფილტრებს, გარიგების ტიპის არჩევას, დალაგებას, რჩეულებს, მუქ რეჟიმსა და ინტერაქტიულ ROI კალკულატორს.

## გაშვება Windows-ზე

1. დააინსტალირე Python 3.10 ან უფრო ახალი.
2. გახსენი PowerShell ამ ფოლდერში.
3. შექმენი და გაააქტიურე ვირტუალური გარემო:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

4. დააყენე Django და გაუშვი საიტი:

   ```powershell
   python -m pip install -r requirements.txt
   python manage.py runserver
   ```

5. ბრაუზერში გახსენი http://127.0.0.1:8000/

## ფაილების სტრუქტურა

- `config/` — Django პროექტის პარამეტრები და URL-ები
- `properties/views.py` — განცხადებების სანიმუშო მონაცემები
- `templates/properties/home.html` — გვერდის HTML
- `static/css/site.css` — სტილები და მობილური განლაგება
- `static/js/site.js` — ფილტრები, რჩეულები და ROI კალკულატორი

## შესაცვლელი მონაცემები

განცხადებების სათაურები, ფასები, ფოტო ID-ები და ROI მნიშვნელობები თავმოყრილია `properties/views.py` ფაილში. WhatsApp-ისა და Telegram-ის დემო ბმულები `home.html`-შია — გამოქვეყნებამდე ჩაანაცვლე შენი საკონტაქტო მონაცემებით. ფოტოები იტვირთება Unsplash-იდან, ამიტომ ფოტოებისთვის ინტერნეტკავშირია საჭირო.

საიტი საწყისად დემოა: `DEBUG=True` და demo `SECRET_KEY`-ით. საჯარო სერვერზე გაშვებამდე გამოიყენე საკუთარი საიდუმლო გასაღები, გამორთე `DEBUG` და მიუთითე შენი დომენი `ALLOWED_HOSTS`-ში.
